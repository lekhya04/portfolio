# My Portfolio

A React + Vite personal portfolio starter.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Build

```bash
npm run build
```

## Sections

- Hero
- About
- Skills
- Projects
- Experience
- Education
- Certifications
- Achievements
- Contact

## Next steps

Replace the placeholder links, add your resume to `public/resume.pdf`, and add project/profile images under `public/` or `src/assets/`.
